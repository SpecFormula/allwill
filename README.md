## AllWill 團隊的一天（首頁）

六人五島的開發團隊：AllWill 把大家 Spec 之間的衝突、矛盾丟出來，對應的成員放招解掉；你也能親手解衝突、打倒魔王，看 AllWill 號一點點變華麗。

- 首頁：`index.html`
- 遊戲：`crew-game/`（AllWill 船塢守衛戰）

## 組織 Spec 島嶼（`islands/`）

把一個範例組織的 spec 畫成島嶼：每座島是一個單位、每座橋是一份約定。按「播放」看 Richard（PM）發出一份 Plan 後，AllWill 怎麼在開工前檢查約定、找出對不上的地方，把問題送到對的人手上。

- 單檔網頁：`islands/index.html`（three.js，從 CDN 載入，不需要 build）
- 本機預覽：`python3 -m http.server`，開 http://localhost:8000/
